# My Daily Expenses 💰

A simple, fast, and lightweight personal expense tracker web app — built to help you record and manage your daily spending with ease. No sign-up required. Works fully offline in any browser.

---

## Features

- **Add expenses** with date, amount, category, and an optional note
- **8 categories** — Food & Drinks, Transport, Shopping, Bills & Utilities, Health, Entertainment, Education, and Others
- **Daily, Weekly, Monthly, and Yearly** spending summaries
- **Doughnut chart** for visual category breakdown
- **Filter and sort** your expense list by category or amount
- **Auto-save** — all data is stored locally in your browser (no server needed)
- **Mobile-friendly** — works great on phones and tablets
- **Pi Browser Edition** — themed in Pi Network purple & gold, ready for App Studio

## Getting Started

### Option 1 — Run locally

1. Clone or download this repository
2. Open `index.html` in any modern browser
3. Start tracking your expenses!

```bash
git clone https://github.com/yourusername/my-daily-expenses.git
cd my-daily-expenses
open index.html
```

### Option 2 — Host on GitHub Pages

1. Fork or upload this repository to your GitHub account
2. Go to **Settings → Pages**
3. Under **Source**, select the `main` branch and click **Save**
4. Your app will be live at:

```
https://yourusername.github.io/my-daily-expenses
```

### Option 3 — Deploy on Netlify

1. Go to [netlify.com](https://netlify.com) and sign in
2. Drag and drop the project folder onto the Netlify dashboard
3. Get an instant shareable URL

## Pi Browser (App Studio)

A Pi-themed version (`index-pi.html`) is included, styled in **purple & gold** to match the Pi Network aesthetic.

To add it to Pi Browser App Studio:
1. Host the file online (GitHub Pages or Netlify)
2. Open **Pi Browser → App Studio**
3. Create a new app and paste your hosted URL
4. Set your app name, description, and icon
5. Save — your app appears on your Pi Browser home screen
